# Runnable code and milestone verification
Each code artifact must say: language/runtime/version, our code/source adaptation/official example, executable vs pseudocode, tested vs untested, dependencies, instructions, input, output and run evidence. Keep runnable snippets as real files; avoid code shown in HTML that differs from the tested lab. Record commands and exit codes in RUN_LOG.json. For databases use exact engines, setup/teardown scripts, data inserts and assertions. For ML use tiny deterministic inputs and tested numerical properties. Benchmark only under recorded conditions; report warmup, sample size and hardware. Distinguish a reproducible protocol from measured data. Include errors and recovery, not just a happy path.
