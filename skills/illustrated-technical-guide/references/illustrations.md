# Illustration grammar (original diagrams)
Storyboard every meaningful figure: question, key takeaway, real inputs/outputs, components, labels, evidence and omissions. Choose grammar by mechanism: relational row diagrams for SQL joins/grouping; tensor grids for attention; timelines for concurrency; packet lifelines for networks; trees/traces for algorithms; annotated plots for benchmarks. Use original accessible SVG/HTML with a numbered caption, alt/aria description, short surrounding explanation and visible provenance. Avoid abstract input→process→output boxes when a concrete trace is possible. Verify labels, arrow semantics, units and values. Editorial styling: warm ivory, ink typography, quiet teal/coral/slate/sand accents, restrained lines and plenty of whitespace. Review at desktop/mobile sizes; screenshots without inspection are not a passed review. Source images must not be copied without rights.

## Visual grammar
- Canvas `#f8f9fb`, ink `#3a424a`, border `#cbd0d5`, connectors `#535a62`.
- Primary semantic accents: blue `#2d92d5`, green `#2e9e52`, orange `#ee8517`, pink `#d82f79`; reserve neutral gray for secondary elements.
- Use Inter/Source Sans 3/Arial for titles and interface text; ui-monospace/Consolas for identifiers, logits, sample rows and code; embed fonts only when licensing permits.
- Agree on a **book-wide color registry** before illustrating (a color mapping is stable within any multi-figure example). Color never carries information alone.
- White/light-gray cards, 8–14px corner radii, 1.5–2.5px dark borders, 16–24px typical padding; minimum readable font size at actual mobile display. Avoid gradients, glow, over-decoration, crowded legends, and gratuitous icons.
- Present actual intermediate values and explain provenance: source-reported, independently reproduced, derived, synthetic, hypothetical, or unverified.

## Building a figure
Draw figures as original SVG, generated by a script in the guide folder so each value comes from the lab or the cited source. Use semantic shapes and real example records, exact numeric calculations, aligned callouts, and captions. Make paths inspectable and editing possible. Run an XML parser and PNG rendering check. No performance values without measured test logs.
