# Teaching design and chapter purposes
Map prerequisites and assign measurable outcomes. Use the four Diátaxis purposes intentionally: tutorial (learning through action), how-to (perform a task), explanation (understanding), reference (look-up facts). A guide can include all four, but do not force each purpose into each chapter. Define a reader starting state, first success, checkpoints and exit skill. Use one recurring authentic example and gradually increase difficulty. Prefer small tested exercises and guided prediction questions. A chapter is complete when its learning objective is demonstrably met, not after an arbitrary number of diagrams or words.
