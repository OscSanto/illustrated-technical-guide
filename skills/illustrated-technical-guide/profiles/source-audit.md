# Optional source-faithful reconstruction
Activate only when the request supplies or explicitly identifies a specific article, paper, project or implementation to reconstruct. This is an **extension** of general teaching, not a replacement.

Before writing, inventory every substantive source section, algorithm, code fragment, equation, dataset, configuration, chart, result, limitation and comparison. Use `source_coverage.csv` with `claim_id,source_url,source_locator,claim_text,critical,disposition,destination_anchor,evidence,notes`. Each item must be `covered`, `partial`, `omitted`, `unverifiable` or `contradicted` with a justified disposition. Critical omissions and contradictions block publication. Separate multiple named systems and document disagreements. Use precise provenance for every artifact. Label original source pseudocode vs. source adaptation vs. our independently written pseudocode. Quote minimally; redraw illustrations originally. Compare numerical tables systematically and report source inconsistencies without silently changing them. A URL list and a handful of sampled claims is not an exhaustive audit.
