# Mathematical / algorithmic explainer
Use for ML, algorithm analysis, cryptography, optimization and numerical methods.

Sequence: motivating example → definitions with shapes/units → concrete mechanism figure → derivation with assumptions and intermediate algebra → worked numerical example → labeled pseudocode → executable reference implementation when practical → numeric unit tests / edge cases → complexity and limitations. Use actual TeX typesetting (offline SVG or another explicitly supported renderer), not improvised Unicode formula strings. Verify dimensions, tolerances and expected numerical outputs. A valid derivation is not proof that a proprietary system uses the equation.
