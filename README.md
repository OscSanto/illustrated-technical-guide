# Illustrated Technical Guide Skill

Open `index.html` in a browser for a self-contained demo. `SKILL.md` is the reusable instruction file for an AI coding assistant or skill-compatible environment.

To create a new guide, give the assistant the skill and a topic, for example: "Using this skill, create a 12-chapter illustrated guide to transformer attention, including equations, worked examples, and implementation details."

The template recreates the source guide's *layout and educational composition*, not its original prose, artwork or brand. Replace the sample text and diagrams with your own content. No dependencies or build steps are required.
