PostgreSQL LEFT JOIN: trace actual rows

In a LEFT JOIN, every matching right-side row produces one output row. A left-side row with no match produces a row whose right columns are NULL.

1. Follow the mechanism

Our original SVG illustration · Toy dataset/values · Not source artwork or benchmark evidence

2. Reproduce the result

Our example · PostgreSQL SQL, unexecuted locally

CREATE TABLE customers (id integer PRIMARY KEY, name text NOT NULL);
CREATE TABLE orders (id integer PRIMARY KEY, customer_id integer REFERENCES customers(id), amount integer);
INSERT INTO customers VALUES (1, 'Ada'), (2, 'Ben'), (3, 'Cleo');
INSERT INTO orders VALUES (101, 1, 30), (102, 1, 22), (103, 2, 12);
SELECT c.name, o.id, o.amount
FROM customers AS c LEFT JOIN orders AS o ON o.customer_id = c.id
ORDER BY c.id, o.id;

The result has four rows: two for Ada, one for Ben, and one unmatched row for Cleo. A WHERE filter on o.amount can remove the NULL row and change the effect of the outer join.
