Transformer Attention: trace a numerical example

Scaled dot-product attention compares a query with each key, divides by the square root of key dimension, normalizes scores with softmax, then takes a weighted sum of value vectors.

1. Follow the mechanism

Our original SVG illustration · Toy dataset/values · Not source artwork or benchmark evidence

2. Reproduce the result

Our example · Python, executed and verified locally

import math
q = [1.0, 0.0]
keys = [[1.0, 0.0], [0.0, 1.0]]
values = [[10.0, 0.0], [0.0, 20.0]]
logits = [sum(a*b for a,b in zip(q,k))/math.sqrt(2) for k in keys]
exps = [math.exp(s) for s in logits]
weights = [x/sum(exps) for x in exps]
out = [sum(w*v[d] for w,v in zip(weights,values)) for d in range(2)]
print([round(w, 4) for w in weights], [round(v, 4) for v in out])

Expected result: [0.6698, 0.3302] [6.6976, 6.6048]

The logits are approximately [0.7071, 0]. Softmax yields approximately [0.66976, 0.33024]. These sum to 1. The weighted sum is approximately [6.6976, 6.6048].
