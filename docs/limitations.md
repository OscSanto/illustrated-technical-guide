# Limitations and evidence
- This repository is a specification, templates, and local static validation tools; it cannot independently guarantee research accuracy, good teaching, browser rendering, or reproducible output across model runs.
- Current included legacy Jev/PostgreSQL pages are **draft demonstrations**, not publication-quality or source-verified reconstructions.
- The structural fixture demonstrates schema validation, not textbook quality or passing a source-fidelity audit.
- CI runs deterministic validators. It does **not** generate new textbooks or measure model consistency. Evaluation prompt harnesses require user-provided outputs from actual agent runs.
- No benchmark, source claim or rendering is approved simply because its JSON field says `passed`; evidence must be inspected.
